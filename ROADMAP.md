# Product & Engineering Roadmap

## Current Status (MVP)

Implemented foundations:
- Auth and profile bootstrap
- Friends graph
- Chat + stories + memories flows
- Camera-first UX
- Snap Map with ghost mode and RPC location sharing
- Push notification plumbing
- Gemini Live websocket bridge

## Phase 1 — Stabilization (Short Term)

- Improve automated test coverage (unit + integration + E2E smoke).
- Add centralized error reporting/observability.
- Harden offline/PWA behavior and reconnect strategies.
- Audit and optimize heavy renders (map/camera/story player).

## Phase 2 — V1 Readiness

- Presence and typing indicators in chat.
- Better conversation search and unread management.
- Story privacy matrix and close-friends controls.
- Enhanced friend discovery and recommendation.
- Admin dashboard for moderation and abuse handling.

## Phase 3 — Advanced Real-time & AI

- Rich multimodal AI assistant scenarios (camera-aware prompts, translation, summarization).
- Smarter geospatial clustering/heatmap generation.
- Context-aware voice assistant actions in app workflows.

## Phase 4 — Scale & Growth

- Multi-region strategy for realtime and media delivery.
- Feature flags and staged rollout pipeline.
- KPI instrumentation (activation, retention, sharing loops).
- Monetization experiments (premium features, creator tooling).
